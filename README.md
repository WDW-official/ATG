# A Thousand Generation — Next.js website

Responsive Next.js + TypeScript implementation of the ATG website using the supplied website copy.

## Pages
- `/` — editorial homepage
- `/about` — Who We Are, Why We Care, Core Values
- `/programmes` — What We Do + 2024–2026 programmes
- `/impact` — Impact in Action and programme timeline
- `/volunteer` — volunteer benefits, eligibility and signup form
- `/pledge` — Take the Pledge experience
- `/get-involved` — Volunteer / Donate / Partner pathways

## Run
```bash
npm install
npm run dev
```

## Images
Bundled SVG placeholders keep the project self-contained. Replace the files in
`public/images/` with the original ATG photography and transparent logo for production.

## Important
The Donate and Partner pathways intentionally do not invent bank/payment details. They
open an email to the ATG address from the supplied website document until a payment URL,
bank details, or donation platform is provided.
